# Întoarcerea la tine — site oficial

Prototip static (HTML + CSS) pentru viitorul site oficial de prezentare. Proiect separat de pâlnia LIVE.

## Structură

- `index.html` — Acasă
- `metoda.html` — prezentarea publică a abordării
- `despre.html` — despre Iulia
- `lucram-impreuna.html` — moduri de lucru
- `constelatii.html` — întâlniri și evenimente
- `resurse.html` — resurse în pregătire
- `contact.html` — contact
- `styles.css` — design comun, responsive

## Stadiu

**PROTOTIP — nu este pregătit pentru lansare publică.** Meta robots este `noindex,nofollow` până la validarea conținutului, portretului, politicilor specifice noului domeniu și testelor de funcționare.

Nu se colectează formulare și nu se procesează plăți. Nu există magazin activ.

Fotografia este încă referită din domeniul Netlify al pâlniei, temporar; recomandarea este copierea ei ca asset local înainte de lansare. Pâlnia nu este modificată.

**Confidențialitate:** nu publicați MASTER, transcrieri integrale, arhive, materiale de curs sau alte surse private în acest repository public. Conținutul metodei prezentat aici este strict o descriere publică preliminară.

### Netlify

Publicare simplă: **Import from Git → GitHub → intoarcerea-la-tine-site**. Publish directory: `.`; fără comandă de build.
